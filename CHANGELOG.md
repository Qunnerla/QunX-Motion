## 1.0.0-beta.1 — 2026-10-01

First public beta, published at the canonical source.

- One-file HTML motion-graphic clips (GSAP) with a built-in player: scrub bar, chapters, frame-rate picker, subtitles, safe-zone overlay, synthesized sound or the user's own song cut to its beats.
- 6 templates for users without a reference, 8 finished example clips, brand colours from a website, app code or logo.
- Transitions library, camera language (including handheld), motion principles and effects.
- Scripts: quick check, deep QA, MP4 render, brand, beats, footage clips, SVG logo pieces.
- **Lite mode for phones and tablets:** the template detects them and builds a lighter version (motion-blur copies built just in time, fewer copies, lighter canvases) so iPhone pages no longer run out of memory and reload. Desktop keeps the full build. `#lite` / `#full` in the URL forces either.
- QunX Motion License with attribution metadata and integrity rules for AI assistants that load the skill.

Earlier private test builds used different version numbers; numbering restarts here.
